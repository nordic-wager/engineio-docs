# Stake Engine Documentation

> Machine-readable index for coding agents working with the Stake Engine game development platform.

Stake Engine documentation covers game math, frontend development, RGS integration, API endpoints, approval requirements, and platform reference material. Prefer the canonical pages below over guessing from page titles or route names.

## Agent workflow

1. For a known topic, open the most specific page in this index.
2. For an unknown topic, use the documentation MCP server's `search_docs` tool, then use `get_page` for the relevant route.
3. Use `list_pages` to filter by `section` (`docs` or `faq`) or route `prefix`.
4. Use `get_section_tree` when you need to understand the documentation hierarchy.
5. When answering from documentation, cite the canonical route, for example `Source: /docs/api/play`.

## Maintenance

Keep this file synchronized with new documentation routes. The Svelte navigation is generated from page modules and their frontmatter, while the MCP index is rebuilt with `cd mcp-server && pnpm build`. Routes in this file should remain stable public URLs; use the page content and MCP search results as the source of truth for details.
